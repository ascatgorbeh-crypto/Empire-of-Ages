# 🏰 Empire of Ages

A massive civilization-building strategy game combining world exploration, economy, military, diplomacy, and PvP gameplay.

## 📖 About

**Empire of Ages** is an epic strategy game where players start from a small settlement and build a thriving empire. Progress through ages: House → Village → Town → City → Metropolis → Capital → Kingdom → Empire.

### Key Features

✨ **Gameplay Mechanics**
- 🌍 Vast open world with multiple continents
- 🏗️ City building and settlement management
- 💰 Complex economy system
- ⚔️ Strategic military system
- 🤝 Diplomacy and alliances
- 🌙 Dynamic day/night cycle
- 👥 NPC with daily routines
- 💾 Advanced save system

### Civilizations
- 🇮🇷 Achaemenid (هخامنشیان)
- 🇮🇷 Parthian (اشکانیان)
- 🇮🇷 Sassanid (ساسانیان)
- 🇬🇷 Greek
- 🇮🇹 Roman
- 🇸🇪 Viking
- And many more coming soon...

## 🚀 Quick Start

### Requirements
- Godot Engine 4.x (Free)
- Git
- A text editor or IDE

### Installation

1. Clone the repository:
```bash
git clone https://github.com/ascatgorbeh-crypto/Empire-of-Ages.git
cd Empire-of-Ages
```

2. Open with Godot Engine:
   - Launch Godot
   - Click "Import"
   - Select `project.godot`

3. Run the game:
   - Click the Play button (▶️) or press F5

## 🎮 Gameplay Guide

### Controls
- **Arrow Keys / WASD**: Move camera
- **Mouse Scroll / Pinch**: Zoom in/out
- **Right Click**: Pan camera
- **Left Click**: Select/interact
- **Q/E**: Rotate camera
- **ESC**: Menu

### Starting the Game
1. Select your civilization
2. Choose a starting location
3. Begin building your settlement
4. Manage resources and population
5. Expand your territory
6. Build armies and conquer
7. Establish diplomacy with other players
